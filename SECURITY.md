# Security Policy

## Supported Versions

Nabu does not yet publish versioned releases. Security fixes target the current
default branch and the hosted application when that deployment has been
verified. Older commits and deployments are not supported.

## Reporting A Vulnerability

Do not disclose suspected vulnerabilities in a public issue. Use GitHub's
private **Report a vulnerability** flow from this repository's Security tab.

Include the affected URL or commit, reproduction steps, impact, and any sample
file needed to reproduce the issue. Remove personal or confidential document
content before attaching files.

The maintainer will acknowledge a report through the private advisory and keep
coordination there until a fix or disclosure decision is ready.
